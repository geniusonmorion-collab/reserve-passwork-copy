# Сайт Пассворка

Исходный код лендинга Пассворка: светлая и тёмная темы, интерактивные демонстрации продукта и анимации при прокрутке.

## Локальный запуск

Нужны Node.js 22.13 или новее и npm.

```bash
git clone https://github.com/geniusonmorion-collab/reserve-passwork-copy.git
cd reserve-passwork-copy
npm ci
npm run dev
```

Откройте http://localhost:3000. Изменения файлов обновляются в браузере автоматически.

Для проверки сборки:

```bash
npm run build
```

## Где вносить изменения

- `app/` — компоненты страницы, тексты, стили и анимации.
- `app/theme.css`, `app/theme-illustrations.css` и `app/theme-motion.ts` — цвета и поведение тем.
- `public/` — изображения, иконки и шрифты.
- `AGENTS.md` — договорённости по оформлению и работе с проектом.

Проект использует React, TypeScript, vinext / Vite и Framer Motion. Файлы `.env*`, зависимости и результаты сборки исключены из Git.

## Совместная работа

Создайте fork репозитория, внесите изменения в отдельной ветке и откройте pull request в `main` этого репозитория. При наличии доступа на запись можно создать ветку прямо здесь и также открыть pull request.

Публичный доступ позволяет читать код и предлагать изменения. Прямой доступ на запись выдаёт владелец через приглашение в collaborators.

Публикация исходного кода на GitHub и обновление размещённого сайта выполняются отдельно.
