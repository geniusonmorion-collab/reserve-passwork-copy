# Worklog

## 2026-09-11 — Светлая тема для фона хиро

**Что изменилось.** Хиро-фон перестал быть общим для обеих тем и инвертируется вместе
со страницей. `app/passwork-hero.css` — фон, копия и кнопки переведены на токены
(`--pw-hero-ink/-text/-edge/-focus/-button-ink/-button-edge`, `--pw-hero-depth-distant/
-middle/-foreground`); значения тёмной темы не изменились. `app/theme.css` — светлые
значения этих токенов: дневное небо, синие объёмы глубины на тех же эллипсах и блюрах,
тёмный герб «Сделано в России», голубой нижний фейд в `--theme-page`; снят блок, который
красил шапку над хиро в белое, и переопределение `--star-rgb` (звёзды берут страничный
`74 74 74`). `app/theme-motion.ts` — отдельная пара заливок кнопок хиро для светлой темы.
`app/header-navigation.css` — светлые токены дропдаунов больше не привязаны к
`data-over-hero='false'`. `AGENTS.md` — переписан абзац Theme parity, он фиксировал
обратное правило.

**Почему.** Правка заказчика: «инвертировать, как и всё остальное инвертируется в светлой
теме». Через токены, а не через дублирующие селекторы, чтобы композиция, порядок слоёв и
анимации остались одни на обе темы.

**Проверка.** `npm run build` — `✓ built in 419ms`, `Build complete`. `npm run lint` — 5
проблем (2 ошибки, 3 предупреждения), все в нетронутых файлах (`page.tsx`,
`passwork-header.tsx`, `signal-footer.tsx`, `what-you-get-visuals.tsx`), то есть
дореформенный фон. Отсмотрено в headless Chrome через CDP на 1440×900 и 390×844: верх
хиро, низ хиро с переходом в страницу, открытое меню шапки — светлая тема; тёмная снята
для сравнения и не изменилась.

**Правка тона (тот же день).** Первый подбор выглядел грязновато: объёмы глубины были
средне-синими и на бледном небе уходили в серо-лиловое. Небо и все три слоя переведены в
один чистый лазурный ряд (#ffffff → #f0f7ff → #d3e6ff → #b4d5fb, объёмы на #64a6f2 /
#2f7fe0), нижний фейд — на тех же чистых стопах. Звёзды хиро в светлой теме получили свой
`--star-rgb: 56 118 204` вместо страничного серого `74 74 74`.

**Ослабление тона (тот же день).** По правке заказчика фон сделан бледнее: небо
`#ffffff → #f7fbff → #e5f0ff → #cee3fd`, дальний слой с 42/52% до 28/34% альфы, средний
на `#92c3f9 → #aad3fb`, передний на `#6aa8ef → #87bcf4`, фейд на бледно-голубых стопах.
Цвет звёзд не менялся — на более светлом небе они стали заметнее.

**Осталось.** Ничего не коммитил и не пушил. Реального WebGL-шейдера на хиро нет:
`app/hero-background.tsx` c фрагментным шейдером в проекте лежит, но нигде не
импортируется — светлой ветки в нём не делал. Состояния скролла шапки (`desktop-scroll`,
мобильное открытое меню) в светлой теме глазами не проверял.
