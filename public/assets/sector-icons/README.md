# Sector icons

Original SVGs from [Lucide](https://github.com/lucide-icons/lucide/tree/main/icons),
downloaded on 2026-09-09. See `LICENSE` for the upstream license.

The four assets retain their original vector geometry and shared 24×24 view box,
2px strokes, and rounded caps and joins. The site displays them in white via CSS.

- `factory.svg`: production
- `network.svg`: infrastructure
- `landmark.svg`: government
- `shield-user.svg`: personal data protection
