# Sector icons

`badge-check.svg` is the original Lucide SVG downloaded from
https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/badge-check.svg.

Icon page: https://lucide.dev/icons/badge-check

It shares the existing icons' 24 × 24 viewBox, 2 px stroke, round line caps
and joins. The certification icon uses the same white color and hover animation
as the sector icons, scaled to 48 × 48 px to reflect the larger card area.
